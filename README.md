# UI Автотесты для "Stellar Burgers"

Проект содержит автоматизированные UI-тесты для веб-приложения **"Stellar Burgers"**.
Тесты охватывают основные сценарии работы с приложением: регистрацию, авторизацию и работу с конструктором бургеров.

---

## Цель проекта

Выполнение задания по автоматизации UI-тестирования:
- Протестировать функциональность приложения в Google Chrome и Яндекс.Браузере
- Описать элементы с помощью Page Object паттерна
- Подключить Allure-отчет для наглядного представления результатов
- Покрыть основные сценарии:
    - Регистрация пользователя
    - Авторизация разными способами
    - Работа с разделом "Конструктор"

---

## 🧪 Структура тестов

### Тестовые классы:

1. **`ConstructorTest.java`** — Тестирование раздела "Конструктор":
    - Переход к разделу "Булки"
    - Переход к разделу "Соусы"
    - Переход к разделу "Начинки"

2. **`LoginTest.java`** — Тестирование авторизации пользователя:
    - Вход по кнопке «Войти в аккаунт» на главной
    - Вход через кнопку «Личный кабинет»
    - Вход через кнопку в форме регистрации
    - Вход через кнопку в форме восстановления пароля

3. **`RegistrationTest.java`** — Тестирование регистрации пользователя:
    - Успешная регистрация
    - Ошибка для некорректного пароля (минимальный пароль — шесть символов)

---
## 🚀 Запуск тестов

```bash
# Все тесты в Chrome (по умолчанию)
mvn clean test

# Все тесты в Яндекс.Браузере
mvn clean test -Dbrowser=yandex

# Генерация Allure отчета
mvn allure:serve
# Запуск тестов с генерацией Allure результатов
mvn clean test allure:report
```
